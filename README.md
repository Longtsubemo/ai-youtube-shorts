# AI YouTube Channel (finance_mascot)

A simple 5-stage production pipeline for YouTube Shorts.

## Pipeline (5 stages)

```
1. Topic Selection   ->  topic_selection.json
2. AI Research       ->  research.json
3. Script Generation ->  script.json
4. Scene Planning    ->  scene_plan.json
5. Video Generation  ->  video.mp4
```

Each stage reads the previous stage's artifact and writes its own. Stages are
run individually via their CLIs.

## Artifact layout (flat)

```
data/<run_id>/
    topic_selection.json
    research.json
    script.json
    scene_plan.json
    video.mp4
    state.json
```

## Intentionally not part of this architecture

Fact checking, corroboration, evidence/source validation, web retrieval
(SearXNG, BeautifulSoup/httpx, Firecrawl, hybrid retrieval), retrieval traces,
script QA and video QA have all been removed. **Gemini's own knowledge is the
research basis.** The goal is to make the video, not to build a gated
fact-checking pipeline.

## Running the stages

```powershell
python -m pipeline.orchestrator                  # create data/<run_id>/ + state.json
python -m agents.seo.topic_selector --run-id ID  # Stage 1
python -m agents.research.ai_research_cli --run-id ID
python -m agents.script.script_cli --run-id ID
python -m agents.scene_planner.scene_cli --run-id ID
python -m agents.video_generation.video_cli --run-id ID
```

## Components

| Stage | Module |
| --- | --- |
| Topic Selection | `agents/seo/` (`--provider mock` default, `--provider gemini` opt-in) |
| AI Research | `agents/research/ai_research*.py` |
| Script Generation | `agents/script/script_*.py` |
| Scene Planning | `agents/scene_planner/scene_*.py` |
| Video Generation | `agents/video_generation/` |

## Configuration

- `config/channel.py` - the `finance_mascot` channel definition.
- `config/topic_selection.yaml` - Stage 1 scoring weights and pillars.
- `config.CHANNEL.mascot_asset_path` - configurable mascot asset location. The
  asset itself does not exist yet and is **not** generated by this repository.

## Current status

Stages 2-5 are **skeletons**. They create and validate the artifact contract
but do not yet call Gemini or render video; each CLI prints an explicit
`NOT IMPLEMENTED` note. Stage 1 is the only stage with a real implementation.
